# 2025-01-15 RVINST CLI Redesign

## Task
Redesign the rough CLI version (`tests/INST.cc`) from scratch with a modern, user-friendly interface.

## Design decisions (user-chosen)
- CLI style: subcommand-based (`rvinst decode`, `rvinst encode`, etc.)
- REPL mode: yes (interactive loop with `:` commands)
- Output: colored tables (TTY auto-detected) + JSON mode
- Features: encode/decode + register lookup + instruction listing

## Architecture
5 new modules added under `src/Cli/` and `inc/Cli/`:
- **Main.cc** - minimal entry point
- **CliApp** - single-pass arg parser, subcommand dispatch
- **Commands** - 5 subcommand handlers (decode/encode/reg/list/repl)
- **InputParser** - input type detection (hex/binary/assembly), field metadata for all 6 RISC-V types
- **OutputTable** - colored table + JSON formatter, ANSI colors, TTY auto-detection

## Key implementation details
- `CoutSuppressor` RAII guard redirects `std::cout` during backend `Decode()` to suppress debug prints
  - CoutSuppressor itself still uses `std::cout.rdbuf()` (backend code uses cout)
  - All CLI output code uses `std::print`/`std::println` (from `<print>`), NOT `std::cout`
  - `std::println(stderr, ...)` for error messages, `fflush(stdout)` for REPL prompt
- Field mapping: `InstBitsField_` is LSB-first (opcode at idx 0), `FieldMeta` is MSB-first (funct7 at idx 0), formula: `bitsFieldIdx = totalFields - 1 - displayIdx`
- C++26 standard (upgraded from C++23), features used: `std::print`, `std::println`, `std::format`, `starts_with`, ranges
- Build: CMake + Ninja + Clang (MSYS2), `cmake --build build-x86_64 --target INST`
- All em-dashes replaced with ASCII hyphens to avoid Windows encoding issues

## CMakeLists.txt changes
- Replaced `add_executable(${PROJECT_NAME} tests/INST.cc)` with 5 CLI source files
- Added CLI headers via `target_sources`
- Added `RVINST_VERSION` compile definition from `PROJECT_VERSION`
- `CMAKE_CXX_STANDARD` upgraded from 23 to 26
